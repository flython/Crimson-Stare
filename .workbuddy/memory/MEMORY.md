# 血色牌局 Web 版 — 设计共识（2026-08-29 拷问定稿）

## MVP 范围
- 模式：简易模式、标准局（仅 2-4 人）、单人模式（3选1机械荷官 Doloris/Timoris/Mortis + 15张命运牌）
- 事件牌：仅"黑心商贩"（事件牌，效果挂在购买阶段，依赖黑市系统，归 M2，房主可开关）
- 排除：捣蛋鬼（5人）、组队/独狼（6-8人）、暗藏杀机、完整事件池
- 长期：完整模式为目标，角色/黑市牌数量会超过规则书（105黑市/21角色），引擎按可扩展卡池设计

## 排名奖励（做成配置文件可调）
- 2人局(24票)：1st 4票 / 2nd 4筹
- 3人局(20票)：1st 4票 / 2nd 2票2筹 / 3rd 4筹
- 4人局(16票)：1st 4票 / 2nd 2票2筹 / 3rd 1票3筹 / 4th 4筹

## 技术
- TS monorepo：engine（纯TS状态机+效果注册表）/ server（Node+WebSocket 服务端权威，SQLite 存牌局记录）/ web（React+Vite）
- docker-compose 双服务：web(nginx静态) + server(Node)
- 无账号：昵称+房间码+分享链接，localStorage 临时身份，断线重连
- 卡牌 JSON 模板 + 占位卡渲染，图片按 ID→文件名 约定热替换
- 效果实现：硬编码 TS 函数注册表（不造 DSL），引擎只做"阶段前/中/后"时间点框架

## 体验
- 宣告阶段：半结构化（系统算基础牌型，JOKER赋值/技能/芯片逐项弹出，按临时特权证→顺时针排队确认）
- 掉线托管：最小操作原则自动执行，可重连接管；出牌超时120s自动托管（可配）
- UI：暗色牌桌风。色板基色：提示框 #ffc840 / 血红主色 #e9404b / 暗红 #583c42，可在此基础上调整
- 触屏+鼠标统一布局，横屏最优

## 里程碑
- M1：2-4人白板标准局（8阶段全流程+同步+重连+触屏）
- M2：黑市系统（购买/芯片/道具/秘密交易）+ 首批角色 + 简易模式 + 黑心商贩事件
- M3：单人模式（命运牌+骰子+三荷官）

## 用户待办依赖
- M2 开工前：首批角色技能文本 + 黑市牌效果文本（简易模式4角色+黄框黑市牌优先）
- M3 开工前：命运牌15张文本（荷官技能规则书已有，需确认无改动）
