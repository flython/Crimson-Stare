# 22 - 暗扣交互式声明与六七条放宽

Type: task
Status: resolved
Blocked by: 20, 21

## Question

1. **出牌暗扣声明**：出牌阶段提交暗扣时，若所出牌带声明类芯片（改花色/声明牌型等），立即弹出交互面板选择声明值，随 playCards 动作一起提交落库；宣告阶段自动按规则顺序展示（点数花色→最大牌型→芯片效果→技能→道具），无需玩家再操作。
2. **六/七条放宽**：出牌阶段若手牌中芯片可满足六条/七条，手牌区显示提示，选牌上限从 5 放宽到 6/7；引擎 playCards 校验同步放宽（上限 = 5 + 可造额外条数，受手牌张数约束）。

## Notes

- 声明值必须在牌型判定前落库（影响判定），宣告阶段只做展示。
- 声明交互复用 pendingPrompt/resolvePrompt 机制或 playCards 载荷扩展，取对协议改动最小者（docs/protocol.md 同步更新）。
- 依赖 20 号 hand-evaluator 芯片视图定型声明值接口。
- e2e：暗扣带变色墨水出牌 → 声明花色 → 对决判定按声明生效；芯片造六条 → 上限放宽 6 → 判定六条。

## Answer

实现完成，commit c16035f：

**Engine 侧**：
- `DECLARE_TYPE_CHIPS = {"008","009","010","011","012"}` 标识声明类芯片
- `chipViewFromChips(p, declarations?)`：declarations 有值时用声明值替换全开候选（变色墨水"any"→玩家选的花色，数字滑轨"any"→玩家选点数，012百变影像"any"→asJoker，否则按"suit:X,rank:Y"降级为固定候选）
- `Action.playCards` 新增可选 `declarations: Record<string,string>` 字段
- `playCards` reducer：六/七条放宽（`countSixSeven` 统计手牌最大同点数张数，上限=5+额外张数）；声明类芯片校验（出牌含声明芯片时无 declarations 报错 + 花色/点数格式校验），声明写入 `p.declarations`
- `resolveDuel` 传入 `p.declarations` 使判定生效

**Web 侧**：
- `DeclarationDialog.tsx`：全屏遮罩 + 芯片类型自适应 picker（花色/点数/百变影像），默认值为"任意"
- `Table.tsx`：`submit("playCards")` 拦截含声明芯片的出牌 → 弹出 DeclarationDialog → 收集 declarations → `confirmPlayWithDecl` 提交含 declarations 的 action

遗留：宣告阶段展示（只需展示已声明的值，engine 已有 duelResult.category 字段）；六/七条上限提示文字（UI 层面可加）。
