- **ctx 扩展**：`EffectContext` 新增 `effectId`（日志/交互定位），`runTimingQueue` 传入。
- **测试**：`packages/engine/tests/primitives.test.ts`（createGame 白板局 + 手动 ctx，含越界/不足/随机性断言）。
