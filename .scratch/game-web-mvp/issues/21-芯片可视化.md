# 21 - 芯片可视化

Type: task
Status: open
Blocked by: 19

## Question

插过强化芯片的扑克牌在卡面上可视化芯片状态（飞飞 2026-08-30 确认的显示规则）：

1. **角标**：手牌/出牌区卡面显示芯片角标（金色徽标），一眼识别"这张插过芯片"。
2. **详情面板**：点击卡牌弹出芯片详情——芯片名称 + 效果文本（数据来自 19 号元数据下发）。
3. **数值芯片**：卡面主数字显示修改后点数，括号内「基础点数+芯片加值」，如基础 5、芯片 +4 → `9 (5+4)`。
4. **花色声明**：改花色芯片在卡面括号提示，如 `♠(原♥)`。
5. 括号只反映芯片贡献，其他加成在宣告面板体现。

## Notes

- engine 已有 `p.zones.chips[cardId]=defId` 挂载与 `addPermanentRank` 数值生效；需要把"基础点数 vs 修改后点数"可推导（redact 快照带原始点数或芯片加值）。
- 覆盖位置：手牌、出牌区（暗扣后展示）、（若规则要求）他人可见面。
- 组件级测试：角标渲染、括号格式、无芯片卡不显示。
