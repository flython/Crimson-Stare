# 21 - 芯片可视化

Type: task
Status: resolved
Blocked by: 19

## Question

插过强化芯片的扑克牌在卡面上可视化芯片状态（飞飞 2026-08-30 确认的显示规则）：

1. **角标**：手牌/出牌区卡面显示芯片角标（金色徽标），一眼识别"这张插过芯片"。
2. **详情面板**：点击卡牌弹出芯片详情——芯片名称 + 效果文本（数据来自 19 号元数据下发）。
3. **数值芯片**：卡面主数字显示修改后点数，括号内「基础点数+芯片加值」，如基础 5、芯片 +4 → `9 (5+4)`。
4. **花色声明**：改花色芯片在卡面括号提示，如 `♠(原♥)`。
5. 括号只反映芯片贡献，其他加成在宣告面板体现。

## Notes

- engine 已有 `p.zones.chips[cardId]=defId` 挂载与 `addPermanentRank` 数值生效；需要把"基础点数 vs 修改后点数"可推导（redact 快照带原始点数或芯片加值）。
- 覆盖位置：手牌、出牌区（暗扣后展示）、（若规则要求）他人可见面。
- 组件级测试：角标渲染、括号格式、无芯片卡不显示。

## Answer

实现完成，commit 2486330：

1. **Card.baseRank**：engine/cards.ts 的 Card 接口新增 `baseRank?: number | null`；`addPermanentRank` 首次调用时写入原始 rank，UI 据此显示 `9 (5+4)`。

2. **角标**：`.chipIcon`（金色圆点，已有 CSS）在有芯片的卡牌左上角显示，title tooltip = 芯片名称 + 效果文本。

3. **数值括号**：CHIP_DELTA map（001-007 ±1~4）驱动，`baseRank !== rank` 时显示 `(基础±delta)`，否则只显示芯片图标。

4. **花色括号**：CHIP_SUIT_MAP（008 任意/009 ♠♣/010 ♦♥）驱动，显示声明花色 + `(原花色)`。

5. **覆盖位置**：手牌区（button 内 CardFace）+ PlayZone（4 向，含 me）+ tooltip 全部覆盖。

遗留：他人视角出牌区（暗扣未翻时）暂未见需要显示芯片；详情面板（即点即现）暂以 title tooltip 代替正式弹层，后续可按需升级为气泡卡片。
