# 05 - 牌桌 UI 交互原型

Type: prototype
Status: ready-for-human
Blocked by: 02

## Question

8 阶段流程在屏幕上怎么走，必须让飞飞摸过再定：

- 牌桌信息架构：黑市区/出牌区/各玩家区/自己手牌区的布局（横屏最优，触屏优先设计，鼠标共存）；
- 宣告面板：半结构化逐项确认（JOKER 赋值→技能→芯片）的排队交互形态；
- 关键微交互：暗选出牌、换牌旋转/计数展示、芯片插入目标牌选择、血筹/车票计数器；
- 占位卡渲染样式（三基色延伸：黑市牌按颜色分类的边框）；
- 产出：可点击 HTML 原型（假数据驱动，不接引擎），飞飞体验后拍板，结论回写本票。

## Answer

**可点击原型已产出：`.scratch/game-web-mvp/prototypes/table-ui.html`（纯前端假数据，浏览器直接打开，触屏/鼠标通用）。飞飞体验后拍板，结论回写本票。**

### 布局（横屏最优，720px 以下自动缩卡）
- 顶栏：回合数 + **8 阶段步进条**（点击任意阶段可直接切换到该阶段的交互形态）+ 目标票数。
- 中央上：黑市区 5 格（价格、叠加血筹角标、效果文本、按分类色边框）。
- 中央下：出牌区（暗扣阶段显示牌背，对决亮牌后带牌型标签）。
- 左右：对手面板（血筹/车票/换牌次数、手牌数量牌背、特权证/翻面徽标）+ 牌堆与弃牌堆计数。
- 底部：自己面板（血筹/车票计数、行动按钮区、手牌横滚行）。

### 各阶段交互形态
- 换牌：点选手牌→换牌按钮（≤3 张），或"停止换牌"一键兑血筹；剩余次数实时显示。
- 出牌：选满 5 张才能暗扣（按钮锁定防误触）。
- 对决：**宣告面板**——宣告队列（1.你 → 2.对手）+ 三步逐项确认（JOKER 赋值选项 → 技能发动/不发动 → 芯片使用），完成后自动滚到下一位宣告者，最后展示结算日志。
- 购买：点黑市卡购买，买后右侧补位推进；叠加血筹随购买取走；"限流阀"演示了**芯片插入弹窗**（选弃牌区目标牌、点数越界自动置灰、插入后牌角芯片标记）。
- 删牌：弹窗选弃牌区牌，第 1 张免费、后续实时显示累计费用、血筹不足拦截。
- 重整：二选一按钮（重洗 / +2 血筹）。

### 视觉
三基色延伸的暗色牌桌：血红 #e9404b（行动按钮/当前阶段/筹码）、暗红 #583c42（面板系）、提示金 #ffc840（焦点/徽标/提示）。黑市牌按分类描边：经济金/删牌紫/容错蓝/互动暗红/牌型绿。占位卡直接可读（点数+花色+效果文本），不依赖美术资源。

### 已知演示局限
假数据不接引擎；结算/对手 AI 行为是定时模拟；宣告选项仅示意（真实实现由引擎 JOKER 求解器提供候选）。

**待拍板**：布局分区、宣告三步形态、黑市卡信息密度、按钮层级是否符合手感；有意见直接说，改动后回写本票。
