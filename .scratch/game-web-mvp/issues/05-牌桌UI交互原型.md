**v4 定为实装基线**（"先这样吧，以后再改"）。界面与交互结论已整合进 spec.md 的「UI 与交互决策」节，实装以该节为准；后续视觉/动效打磨另开票。

## Question

8 阶段流程在屏幕上怎么走，必须让飞飞摸过再定：

- 牌桌信息架构：黑市区/出牌区/各玩家区/自己手牌区的布局（横屏最优，触屏优先设计，鼠标共存）；
- 宣告面板：半结构化逐项确认（JOKER 赋值→技能→芯片）的排队交互形态；
- 关键微交互：暗选出牌、换牌旋转/计数展示、芯片插入目标牌选择、血筹/车票计数器；
- 占位卡渲染样式（三基色延伸：黑市牌按颜色分类的边框）；
- 产出：可点击 HTML 原型（假数据驱动，不接引擎），飞飞体验后拍板，结论回写本票。

## Answer

**可点击原型已产出：`.scratch/game-web-mvp/prototypes/table-ui.html`（纯前端假数据，浏览器直接打开，触屏/鼠标通用）。飞飞体验后拍板，结论回写本票。**

### 布局（横屏最优，720px 以下自动缩卡）
- 顶栏：回合数 + **8 阶段步进条**（点击任意阶段可直接切换到该阶段的交互形态）+ 目标票数。
- 中央上：黑市区 5 格（价格、叠加血筹角标、效果文本、按分类色边框）。
- 中央下：出牌区（暗扣阶段显示牌背，对决亮牌后带牌型标签）。
- 左右：对手面板（血筹/车票/换牌次数、手牌数量牌背、特权证/翻面徽标）+ 牌堆与弃牌堆计数。
- 底部：自己面板（血筹/车票计数、行动按钮区、手牌横滚行）。

### 各阶段交互形态
- 换牌：点选手牌→换牌按钮（≤3 张），或"停止换牌"一键兑血筹；剩余次数实时显示。
- 出牌：选满 5 张才能暗扣（按钮锁定防误触）。
- 对决：**宣告面板**——宣告队列（1.你 → 2.对手）+ 三步逐项确认（JOKER 赋值选项 → 技能发动/不发动 → 芯片使用），完成后自动滚到下一位宣告者，最后展示结算日志。
- 购买：点黑市卡购买，买后右侧补位推进；叠加血筹随购买取走；"限流阀"演示了**芯片插入弹窗**（选弃牌区目标牌、点数越界自动置灰、插入后牌角芯片标记）。
- 删牌：弹窗选弃牌区牌，第 1 张免费、后续实时显示累计费用、血筹不足拦截。
- 重整：二选一按钮（重洗 / +2 血筹）。

### 视觉
三基色延伸的暗色牌桌：血红 #e9404b（行动按钮/当前阶段/筹码）、暗红 #583c42（面板系）、提示金 #ffc840（焦点/徽标/提示）。黑市牌按分类描边：经济金/删牌紫/容错蓝/互动暗红/牌型绿。占位卡直接可读（点数+花色+效果文本），不依赖美术资源。

### 已知演示局限
假数据不接引擎；结算/对手 AI 行为是定时模拟；宣告选项仅示意（真实实现由引擎 JOKER 求解器提供候选）。

**待拍板**：布局分区、宣告三步形态、黑市卡信息密度、按钮层级是否符合手感；有意见直接说，改动后回写本票。

### v2 修订（2026-08-29，飞飞修改意见已落实）

意见：黑市队列放中间，所有玩家四向围绕黑市，出牌区在玩家旁边；玩家旁陈列换牌次数/上限、车票计数器、角色牌、牌堆剩余张数；出牌时牌出现在玩家面前（方位反方向）；个人操作界面含手牌区、牌堆/弃牌堆（标注张数）、道具区，出牌后往前打出。

1. **布局重构为实体牌桌**：黑市居中（含供应堆张数），四个座位四向围绕——上/左/右三个对手 + 底部自己；每个座位旁有**独立出牌区**（座位与中央之间，即玩家"面前"），牌面按座位方位旋转（上 180°、左 90°、右 -90°），模拟围桌观感。
2. **座位信息牌**：角色牌缩略卡 + 车票计数器（票 x/目标）+ 血筹 + **换牌次数 已用/上限**（n/3，特权证持有者 4）+ 牌库剩余张数 + 对手手牌牌背数。
3. **出牌飞行动画**：出牌阶段确认后，选中的手牌从手牌区**飞向自己的出牌区**（朝中央方向），其余玩家出牌带浮现动画。
4. **个人操作台（底部独立）**：手牌横滚区 + **牌堆/弃牌堆分区（各标张数，叠层视觉）** + **道具区**（备用道具卡带"使用"按钮，演示皮下密信 +2 筹）+ 行动按钮区。
5. **四人局演示**：升级为 4 座位（我+3 对手），宣告面板排队 4 人，结算按 4 人局奖励表演示（1名4票/2名2票2筹/3名1票3筹/4名4筹）。
6. 演示数据与交互（换牌/购买/芯片/删牌/重整/宣告三步）全部保留，仍为假数据不接引擎。

### v3 修订（2026-08-29，飞飞意见：阶段同步推进机制）

意见：回合阶段由程序控制；操作界面有"结束阶段"按钮；结束阶段后有结束标记并同步到其他玩家界面；所有人结束后自动推进到下一阶段；每次阶段转场有强提示动画（无需交互），自动缩小到顶上的回合指示器中。

1. **阶段推进改为程序控制**：顶栏步进条改为只读指示器（移除点击切换），阶段流转完全由"全员结束标记"驱动。
2. **"结束阶段"按钮**：出现在每个阶段的操作按钮区；点击后自己打上结束标记，不能再操作手牌（拦截提示）。抽牌/结算为自动阶段（自动补牌/自动结算），确认后即可结束。
3. **结束标记同步**：已结束的玩家座位信息牌显示绿色"✓ 已结束"标记（带浮现动画），模拟其他玩家陆续打标；操作按钮区实时显示"全员进度 x/4"。
4. **自动推进**：全员打标后自动进入下一阶段；回合末（重整结束）自动进入下一回合的抽牌阶段。
5. **转场强提示动画**：阶段切换时全屏暗化+大字"XX阶段 / 第N回合"居中弹出（血红描边+金色大字），停留约 1 秒后**自动缩小飞入顶栏对应的阶段指示格**（无需任何交互），随后加载新阶段内容（抽牌自动补牌、对决自动亮牌背等）。
6. 联动调整：出牌暗扣后需手动点"结束阶段"（体现同步等待）；宣告完成视为全员对决阶段完成，自动转场进结算；开局以转场动画开场。
