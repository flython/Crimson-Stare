# 14 - M2.5 UI 交互组件

Type: task
Status: resolved
Blocked by: 13

## Question

牌桌 UI 支持交互所需的 4 个新组件（grilling Q4/Q6/Q9 已确认）：接 server 推送的 `stateUpdate.pendingPrompt`,渲染选择交互。

## Notes

- 组件（`packages/web/src/components/`）:
  - `TargetPicker`:选玩家,高亮候选玩家头像/座位,点击确认;
  - `CardPicker`:选牌,从指定 zone 高亮,支持多选;
  - `PendingPromptBanner`:顶部横幅「等待 X 玩家选择…」;
  - `DiceRollAnimation`:服务端掷骰结果,前端播 0.5s 动画再显示。
- 风格沿用既有暗色牌桌三基色 `#e9404b / #583c42 / #ffc840`,触屏+鼠标,横屏最优。
- 占位卡:图片缺失保留纯色块 + 叠加效果原文。
- 简易模式入口开放,标准/单人口灰显「敬请期待 M3」(grilling Q6)。
- 与 05 号票据 UI 原型（宣告三步面板、芯片插入弹窗）衔接,复用交互模式。

## Answer

已落地（2026-08-30，`packages/web/`；`npm run build`（tsc + vite build）通过，eslint 无告警，SSR 冒烟渲染 8 场景全过）。

**组件清单**（`packages/web/src/components/`，桶导出 `index.ts`）：
- `TargetPicker.tsx`：选玩家（`pendingPrompt.kind === "choosePlayer"`）。props = candidates 玩家 id + players 牌桌信息（TablePlayer）；候选玩家高亮头像/座位可点，非候选置灰；单选 + 确认按钮（≥44px，触屏+鼠标）。
- `CardPicker.tsx`：选牌（`kind === "chooseCard"`）。props = candidates 牌 id + from 区域 + 区域牌列表；多选（checkbox 风格）+ 确认；非候选牌置灰；占位卡牌面 = 纯色块 + 点数/花色文本（沿用 05 原型 .card 视觉，图片缺失回退）。
- `PendingPromptBanner.tsx`：顶部横幅，接 `stateUpdate.pendingPrompt`（裁剪后形状 `ViewPendingPrompt`）。三态：等待我（血红强调横幅 + 激活对应 Picker）/ 等待其他玩家（"等待 X 选择…"）/ 无挂起（返回 null）。等待判断用 `pendingPromptForMe` 类型守卫。
- `DiceRollAnimation.tsx`：纯展示骰子。`result`（1-6）变更后播 0.5s 滚动动画（旋转 + 面数轮换）再定格显示结果并回调 onDone；`result === null` 显示等待态。

**与现有 store/WS 的衔接**：web 包此前无 store 无 WS（App 为占位，server 为占位入口）。组件为 props 驱动、无内部依赖：`PendingPromptBanner` 收 prompt/players/cardsByZone，`onResolve(choice)` 由上层注入（联调时接 WS 快照）；`sendResolvePrompt` 在 `lib/resolvePrompt.ts`。`lib/types.ts` 定义 `ViewPendingPrompt`/`TablePlayer` 及 `pendingPromptForMe`/`pendingPromptWaiter` 工具。

**简易模式入口**：`App.tsx` 开放「简易模式」入口（4 角色 + 24 黄边黑市），标准模式/单人模式灰显「敬请期待 M3」（grilling Q6）。当前无大厅/建房 UI，入口仅选择态提示，建房/大厅流程待 15 号联调接入。

**遗留**：
- `resolvePrompt` 顶层消息协议未定：按票据约定定义 `{ type: "resolvePrompt", choice }`（playerId 由 server 从连接身份推断），与 engine Action（`{ type:"resolvePrompt", playerId, choice }`）的关系、是否走 protocol 的 `action` 包装，待 15 号联调确认。
- `chooseCard from="draw"` 时本人亦不可见牌面（redact draw 恒为 count），区域牌列表由调用方传空，组件以候选 id 兜底渲染。
- 全局样式集中在 `src/styles.css`（暗色三基色 tokens + 按钮/弹层/卡牌/骰子/模式选择），后续牌桌主体复用。
