# 18 - 卡牌图片上图

Type: task
Status: open
Blocked by: —

## Question

web 卡面从 config JSON 的 `image` 字段（`assets/cards/<类>/<ID>.png`）加载真实图片并渲染到扑克牌/黑市牌/角色牌卡面上，图片缺失或加载失败时回退现有占位渲染（卡名+分类色块+效果文本），不得白屏或布局抖动。

## Notes

- config/cards/*.json 每条已含 `image` 字段；图片按 ID→文件名约定热替换，无需改数据。
- 图片通过 server 下发的元数据或构建期拷贝进 web 静态资源（Vite `public/` 或 import），二选一以实现最简为准。
- 覆盖卡面位置：手牌、出牌区、黑市 5 格、座位角色牌缩略卡。
- 组件级测试断言：有图渲染 img、无图回退占位。
